# 웹툰과 게임 스토리 비교

공식 네이버 웹툰의 공개 본문을 이용해 아래 사실을 대조했다. 회차 색인 수집·문자 인식과 모든 컷의 수동 정독은 구별한다. 전체 장면의 문장별 충실도 검수가 끝났다는 뜻은 아니다.

공개 본문 경계: 표시 회차 **311화**, URL의 no=312 · 시즌 1 마지막화. **우리엘 현현까지이며 마왕 선발전은 정산 전이다.** 후기는 스토리 근거에서 제외했다.

게임의 마계의 봄 엔딩을 앞당겨 자르지는 않았다. ST148의 거대 설화 성장 전제 일부는 웹툰에 있으나 열차 위 전개는 미각색이다. ST149–ST153은 기존 소설 기반 조사로 작성했으며 소설 원문 대조가 남아 있다.

아래 본문 위치는 공식 회차 안의 `comic content` 이미지 순서(1부터)다. URL no와 화면의 표시 회차는 1 차이가 난다. 원본 패널·OCR 전문은 배포하지 않는다. 새 대사는 게임 각색 문장이다.
